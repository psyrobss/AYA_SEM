Este ambiente interativo foi projetado para guiar você em cada decisão analítica, do pré-processamento das matrizes no lavaan até a redação competitiva para periódicos internacionais de alto impacto.

1. Contexto dos Dados e Amostra da UDV

Os dados foram coletados junto a sócios da União do Vegetal (UDV). A amostra inicial contou com N = 1.414 respondentes. Após o tratamento de dados faltantes (missing data), restou uma amostra analítica robusta de N = 1.365.

Por que esta amostra é especial para publicações?

  • A maioria dos estudos com ayahuasca conta com N reduzido (< 100).
  • Com N > 1.000, o poder estatístico permite rodar modelos de 2ª ordem com estimadores assintóticos robustos.
  • Ambiente institucional estável: reduz o ruído de "set & setting" não controlado.

Delineamento Transversal (Cross-Sectional)

Coleta em ponto único no tempo. Embora a SEM desenhe setas direcionais com base na teoria, não podemos afirmar causalidade no sentido biomédico estrito. No artigo, usamos verbos como "previu", "associou-se" ou "explicou variância", nunca "a ayahuasca curou".

4. Pipeline Completo no R (lavaan & semPlot)

Este script foi otimizado para lidar com dados ordinais através do estimador WLSMV (versão robusta do DWLS). Navegue pelas abas para inspecionar cada bloco do código: 

# --- 1. PREPARAÇÃO DO AMBIENTE ---
install.packages(c("lavaan", "semPlot", "tidyverse"))
library(lavaan)
library(semPlot)
library(tidyverse)

# Leitura da base e conversão para ordinal (Essencial para DWLS)
dados <- read.csv("banco_udv_1365.csv")

# Inspecione se os itens invertidos (.r) já estão com pontuação alta = melhor QV
summary(dados[, c("WhB.3.Dor.r", "WhB.26.Ult.Semana.r")])
# --- 2. ESPECIFICAÇÃO DO MODELO (Sintaxe lavaan) ---
model_sem <- '
  # [CFA] 1ª Ordem BREF (Qualidade de Vida)
  Fisico   =~ WhB.3.Dor.r + WhB.4.TratMed.r + WhB.10.Energ + WhB.15.Locomocao + WhB.16.Sono + WhB.17.AtvDiarias + WhB.18.Capac.Trabalho
  Psico    =~ WhB.5.AprVid + WhB.6.SentVida + WhB.7.Concent + WhB.11.AceitAparencia + WhB.19.Satisf.SiMesmo + WhB.26.Ult.Semana.r
  Social   =~ WhB.20.Relac.Pess + WhB.21.Vid.Sexual + WhB.22.ApoiAmig
  Ambiente =~ WhB.8.SentSegurVid + WhB.9.AmbFis + WhB.12.Dinh.Necess + WhB.13.Disp.Inform + WhB.14.Lazer + WhB.23.Cond.Mora + WhB.24.Aces.Saude + WhB.25.Transporte

  # [CFA] 1ª Ordem SRPB (Facetas Espirituais)
  Conexao    =~ SR.Conex.EpocDif + SR.Conex.Tol.Estresse + SR.Conex.ComprOutros + SR.Conex.Confort.Tranq
  Sentido    =~ SR.SentVid + SR.SentVid.Cuidar + SR.SentVid.Finalidade + SR.SentVid.Motiv
  Admiraca   =~ SR.Admir + SR.Admir.Bel + SR.Admir.Inspir + SR.Admir.Agradec
  Integracao =~ SR.Integr.Lig.Men.Corp.Alm + SR.Integr.Eq.Men.Corp.Alm + SR.Integr.Acord.Viv.Sent + SR.Integr.Harmon.Viv.Sent
  ForcaEsp   =~ SR.Forc.Esp + SR.Forc.Esp.Epoc.Dif + SR.Forc.Viv.Melh + SR.Forc.Feliz
  PazInt     =~ SR.Paz.Consigo + SR.Paz.Interior + SR.Paz.Necess + SR.Paz.Harmon
  Esperanca  =~ SR.Esp + SR.Esp.Vida + SR.Esp.Otim.Qual.Vid + SR.Esp.Otim.Incert
  Fhe        =~ SR.Fe.BemEst + SR.Fe.Confort.Dia + SR.Fe.Forc.Dia + SR.Fe.Desfr.Vid

  # [CFA] 2ª Ordem: Espiritualidade Geral
  Espiritualidade =~ Conexao + Sentido + Admiraca + Integracao + ForcaEsp + PazInt + Esperanca + Fhe

  # [ESTRUTURAL] Regressões do Mecanismo
  Espiritualidade ~ a1*FAy + a2*T.UDV

  # [ESTRUTURAL] Desfechos controlando por Socioeconômico
  Fisico   ~ b_fis*Espiritualidade + Age + Masc + Rend.Fami
  Psico    ~ b_psi*Espiritualidade + Age + Masc + Rend.Fami
  Social   ~ b_soc*Espiritualidade + Age + Masc + Rend.Fami
  Ambiente ~ b_amb*Espiritualidade + Age + Masc + Rend.Fami

  # [MEDIAÇÃO] Efeitos Indiretos (a * b)
  Ind_Freq_Psico    := a1 * b_psi
  Ind_Freq_Ambiente := a1 * b_amb
  Ind_Freq_Social   := a1 * b_soc
  Ind_Freq_Fisico   := a1 * b_fis

  Ind_Tempo_Psico   := a2 * b_psi
'
# --- 3. EXECUÇÃO DO MODELO COM DWLS / WLSMV ---
fit_sem <- sem(
  model       = model_sem,
  data        = dados,
  ordered     = TRUE,       # Declara que as variáveis de resposta são ordinais
  estimator   = "WLSMV",     # Versão robusta do DWLS (ideal para Likert de 5 pontos)
  std.lv      = TRUE        # Fixa a variância das latentes em 1.0 para padronização
)

# Extração dos índices de ajuste recomendados para publicação
fitMeasures(fit_sem, c("cfi.robust", "tli.robust", "rmsea.robust", "srmr"))

# Tabela de coeficientes estruturais e R²
parameterEstimates(fit_sem, standardized = TRUE) %>%
  filter(op %in% c("~", ":=")) %>%
  select(lhs, op, rhs, std.all, pvalue, ci.lower, ci.upper)
# --- 4. EXPORTAÇÃO GRÁFICA EM ALTA DEFINIÇÃO (300 DPI) ---
tiff("Figure1_PathDiagram_JPD.tiff", width = 3000, height = 2200, res = 300)

semPaths(
  fit_sem,
  what         = "std",         # Apresenta coeficientes padronizados
  layout       = "tree2",       # Organização em árvore hierárquica
  style        = "lisrel",      # Estilo clássico para periódicos científicos
  residuals    = FALSE,         # Remove poluição visual das flechas de erro
  exoCov       = FALSE,         # Omite correlações bidirecionais das exógenas
  edge.label.cex = 0.85,
  sizeLat      = 9,
  sizeMan      = 5,
  color        = list(lat = "#f0fdf4", man = "#ffffff"),
  edge.color   = "#1e293b"
)

dev.off()

6. Guia Passo a Passo para Escrever o Artigo

Introdução (Sem HARKing)

Construa o funil conceitual partindo do contexto global da ayahuasca até as hipóteses formais:

  • Parágrafo 1: A transição do uso indígena para contextos urbanos organizados (UDV) e o interesse psicofarmacológico.
  • Parágrafo 2: A virada salutogênica: em vez de apenas medir redução de depressão em doentes, estudar bem-estar sustentado em usuários experientes.
  • Parágrafo 3: A espiritualidade como mecanismo psicológico (teoria da conectividade e comunhão).
  • Parágrafo 4: Apresentação das Hipóteses: postular que o engajamento ritual prediz qualidade de vida mediado pela espiritualidade, superando a renda.

Métodos & Análise de Dados

Termos técnicos indispensáveis para validar o artigo perante revisores quantitativos:

  • Amostra: Descrever critérios de triagem (1.414 → 1.365 analítico) e consentimento ético.
  • Justificativa do DWLS: Citar Li (2016) para demonstrar por que o estimador para dados ordinais é superior ao ML tradicional com escalas Likert.
  • Fator de Segunda Ordem: Explicar a hierarquia psicométrica: 32 itens → 8 facetas de 1ª ordem → 1 Fator Geral de Espiritualidade.
  • Pontos de Corte de Ajuste: Declarar a priori CFI/TLI ≥ 0.95 e RMSEA ≤ 0.06 como parâmetros de bom ajuste.

Resultados: A Ordem da Narrativa

Nunca comece interpretando; reporte a estrutura matemática estrita:

  • 1. Modelo de Mensuração: Reportar que a CFA confirmou cargas fatoriais > 0.40 para todos os itens e CFI = 0.99.
  • 2. Modelo Estrutural: Apresentar a tabela APA de coeficientes diretos (β, SE, z, p).
  • 3. O Efeito Buffer: Comparar visualmente na tabela que a espiritualidade explica 42% da variância ambiental frente a 2% da renda.
  • 4. Mediação: Reportar os coeficientes indiretos (delta method ou bootstrap) confirmando a via FAy → Espiritualidade → QV.

Discussão: Como "Vender" o Paper

Conecte os dados à literatura internacional de psicodélicos:

  • Riqueza Interna vs. Externa: Discutir que a espiritualidade atua como recurso cognitivo protetor que ressignifica o ambiente material.
  • A Relevância da Frequência: A necessidade de integração e ritualização contínua; não há "imunidade perpétua" conferida pelo tempo passado.
  • Limitações Obrigatórias: Reconhecer o viés de auto-seleção (quem respondeu ao questionário provavelmente gosta da instituição) e a natureza transversal.

7. Glossário Psicométrico e Estatístico

DWLS (Diagonally Weighted Least Squares) / WLSMV
Estimador robusto de equações estruturais projetado especificamente para variáveis categóricas ou ordinais (escalas Likert de 1 a 5). Diferente da Máxima Verossimilhança (ML), não exige normalidade multivariada contínua.
Variável Latente vs. Observada
Variável Observada (manifesta) é aquela medida diretamente pelo questionário (ex: nota de 1 a 5 no item de sono). Variável Latente é o construto abstrato livre de erro de mensuração, deduzido a partir da covariância compartilhada de múltiplos itens (ex: Domínio Psicológico).
CFI (Comparative Fit Index) & TLI (Tucker-Lewis Index)
Índices de ajuste incremental que comparam o modelo hipotetizado a um modelo nulo basal. Valores acima de 0.95 indicam excelente conformidade teórica aos dados. O valor 0.99 obtido neste estudo demonstra precisão quase perfeita.
RMSEA (Root Mean Square Error of Approximation)
Índice de discrepância residual por grau de liberdade. Avalia o quanto o modelo difere da matriz populacional verdadeira. Valores ≤ 0.06 indicam ajuste estrito; até 0.08 é considerado adequado na literatura psicométrica.
Mediação (Efeito Indireto: a × b)
Ocorre quando a influência de uma variável independente (X: Frequência) sobre uma dependente (Y: Qualidade de Vida) transita por uma variável intermediária (M: Espiritualidade). O efeito indireto estatisticamente significativo prova a existência desse mecanismo condutor.
Heywood Case / Casos Extremos de R²
Ocorre quando uma estimativa atinge fronteiras teóricas (ex: variância de erro zero ou R² = 1.00, como visto no item Fe.Confort.Dia). Em amostras grandes, geralmente reflete um indicador quase perfeitamente colinear ao construto latente, devendo ser auditado no texto do artigo.
HARKing (Hypothesizing After Results are Known)
Prática inadequada de apresentar achados inesperados como se fossem hipóteses formuladas antes da coleta. Para evitar isso, formulamos hipóteses baseadas em teorias consolidadas de engajamento ritual e resiliência psicológica antes de relatar a assimetria entre Frequência e Tempo.
